## 各界面组件说明

### 界面 1：首页 - 标准可视化

首页默认界面。图 1 和图 2 是同一个首页的两个 tab 状态，不是两个独立页面。顶部是标准检索框；下方展示当前有效标准数量、最近周期更新时间、周期更新状态。周期更新进行中时，只显示「周期更新 · 进行中」；周期更新已完成时，在同一行继续显示新增现行标准数、失效标准数、失败标准数。摘要区下方留出一段距离后进入 tab 区，默认选中「标准可视化」，用 Embedding Atlas 展示所有有效标准：每个标准是一个小点，并根据 embedding 内容聚类。点击散点后进入对应标准详情界面。

### 界面 2：首页 - 最新标准列表

首页第二个 tab 状态。顶部仍然保留标准检索框和两行摘要小字；点击「最新标准列表」tab 后，展示最近一个月的有效标准列表。列表上方左侧是标准检索框，提示文字为「标准号或标准名称，检索范围为全部有效标准」，支持标准号精确检索和标准名称关键词检索；检索框右侧的按钮为「检索全部」。检索范围不限于最近一个月，而是数据库中的全部有效标准：未输入检索内容时列表展示最近一个月的有效标准，一旦发起检索则在全部有效标准中匹配。右侧是来源下拉框，可选择全部、国家标准、行业标准、地方标准，不单独设置筛选按钮；来源下拉作用于当前结果集。标准列表字段包含序号、标准号、标准名称、来源、分类、发布日期、实施日期。分类字段用于展示来源下的细分信息：国家标准显示强制性国家标准、推荐性国家标准、指导性技术文件；行业标准显示行业名称；地方标准显示具体地区。列表支持分页，默认每页 10 条，并可通过下拉框切换为 25 条/页、50 条/页；分页信息展示当前筛选条件下的标准总数和当前页码，例如「每页显示 10 条，共 18 条标准，1 / 2」，当前页数字标蓝。

### 界面 3：标准检索结果

用户在首页输入文字并点击检索后进入该界面。页面左上角有圆形返回按钮，点击返回上一层。页面顶部检索框位置与界面 1、2 保持一致，不随结果变化移动，也不显示来源下拉框。结果标题区域右上角有「检索历史」按钮，按钮位于表格外部。检索框下方展示「标准检索结果」标题、小字总结果数和检索时间，例如「共 18 条检索结果，检索时间：2026/8/12 15:45:23」，其中总结果数高亮为蓝色。下方是标准结果列表，列表字段为序号、标准号、标准名称、来源、分类、发布日期、实施日期、相似度得分；得分高亮为蓝色，结果按 score 从高到低排列。列表行可点击，进入标准详情界面。

### 界面 4：检索历史浮层

该界面是界面 3 中点击「检索历史」按钮后的悬浮框，不是独立页面。页面左上角同样保留圆形返回按钮。浮层从结果区右上角的「检索历史」按钮展开，悬浮在检索内容之上，只展示检索历史列表；每条历史左侧是检索输入内容，右侧是检索时间，历史记录按时间由新到旧排列。浮层默认最多显示 10 条历史记录，超过 10 条时出现纵向滚动条继续下拉查看。点击某条检索历史后，直接切换到该历史对应的检索记录，检索框内容、检索结果和检索时间同步回填；该历史记录仅更新排序时间后显示在历史列表第一条。点击浮层外任意位置后关闭浮层。

### 界面 5：标准详情

从界面 1 的散点图、界面 2 或界面 3 的标准列表点击某个标准后进入该界面。页面左上角有圆形返回按钮，点击返回上一层。页面顶部用大字展示标准名称，标准名称后放来源网站 logo 图片作为点击入口，点击后跳转到当前标准所在官方网站；下一行小字展示标准号、类型、发布时间、实施时间，其中类型由来源和分类组合得到，例如国家标准 / 推荐性国家标准、行业标准 / 通信、地方标准 / 山西省。下方以 tab 形式展示 4 个 Markdown 产物：overview.md、structure.md、logic.md、body.md。每个 Markdown tab 内部都有「视图 / 源码」切换按钮，位于内容区左上角；内容区右上角放复制图标，在视图和源码两种状态下都可复制当前 Markdown 内容。

## 交互说明

首页检索框输入内容并点击检索后，进入标准检索结果界面。首页的两个 tab 用于在「标准可视化」和「最新标准列表」之间切换。界面 3、4、5 左上角的返回按钮用于返回上一层，逐步回到首页。

最新标准列表支持标准号精确检索、标准名称关键词检索、来源下拉筛选、分页和每页条数切换。列表默认展示最近一个月的有效标准，发起检索后在数据库中的全部有效标准内匹配。页面上有两个不同的计数：顶部两行摘要中的有效标准数量是全库总数，只随周期更新变化，不受检索和筛选影响；列表左下角分页区的标准总数是当前检索条件和来源筛选下的结果数，实时变化。鼠标覆盖标准行时，行背景变为浅蓝色；点击列表中的任意标准，进入标准详情界面。右侧分页导航默认显示前几个页码、省略号和末页；进入第二页及之后时，页码前显示「上一页」按钮。当前页页码高亮为蓝色。

标准检索结果按 score 相似度分数降序排列。结果区右上角的「检索历史」按钮可打开检索历史浮层。点击结果中的任意标准，进入标准详情界面。

检索结果页点击「检索历史」按钮后打开检索历史浮层。点击某条历史记录时，不重新发起检索，而是切换到该历史记录快照：检索框内容、检索结果和检索时间一起回填；该历史记录仅更新排序时间后显示在历史列表第一条。

标准详情页点击标准名称后的来源网站 logo 跳转当前标准所在官方网站；点击 Markdown tab 切换产物内容；在产物内容区内点击「视图 / 源码」切换展示方式；点击内容区右上角复制图标复制当前 Markdown。

以上 5 个界面覆盖 README 中的标准导入结果展示、标准目录管理、标准详情与产物查看、标准检索分析、多来源状态展示。前端不提供手动上传、手动解析、手动索引操作。
